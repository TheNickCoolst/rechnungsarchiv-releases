# Rechnungsarchiv – App-Downloads

Hier liegen die fertigen Installationsdateien der Rechnungsarchiv-App. Der Quelltext ist privat.

## Android

1. Unter [Releases](https://github.com/TheNickCoolst/rechnungsarchiv-releases/releases/latest) die Datei `Rechnungsarchiv.apk` herunterladen.
2. Datei antippen und „Installation aus dieser Quelle erlauben“ bestätigen.
3. App öffnen und einmal mit dem Passwort anmelden.

Die App ist für den privaten Gebrauch gedacht: Ohne das Passwort lässt sie sich nicht nutzen.
